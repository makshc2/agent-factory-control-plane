Ризикові місця:

- **404 провайдерів (3.2/3.3):** перевірка існування гілки виконується ЛИШЕ у гілці 404 листингу і ЛИШЕ один раз. Успіх перевірки → `[]`; 404 перевірки → кинути **первинну** помилку листингу (не помилку перевірки) → `not-found` у 3.4. `fetchArtifact` 404 → `null`, без перевірки гілки.
- **Контракт `addProject` (4.1):** тільки `{ ok: true, project }` / `{ ok: false, error: { code, message } }` — без `throw` і без `false`. При `{ ok: false }` список не мутується, форма (6.3) не закривається, `error.message` видимий.
- **`loading` (4.2):** `true` до першого await, скидання лише у `finally`; 4.4 перевіряє це deferred-моком.
- **Заборона `fetch` (3.2/3.3):** усі запити через `createHttp({ baseURL, headers })` з `src/api/http.js`; default export `http` не змінювати.
- **`src/App.spec.js`:** після 6.3 сюїта App упаде без активної Pinia. Додати `createPinia()` до `global.plugins` у цьому тесті (мінімальна правка, заголовок `Factory board` зберегти). Це єдина дозволена правка наявного тесту.
- **Полер (5.1/6.3):** `onUnmounted` → `stop()`, інакше інтервал протікає в тестах 6.4.

Не торкатися: `openspec/**` (крім галочок у `tasks.md`), `src/router/`, `src/main.js`, `src/App.vue`, базові стилі в `src/styles.css`.
